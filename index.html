Create Google Sheet Template
Run this Apps Script once to create a perfectly formatted ATL sheet in your Google Drive — dark theme, frozen headers, correct column widths, and an instructions tab.
Step 1 — Open Apps Script
Go to script.google.com → click New Project → delete any existing code.
Step 2 — Paste the script below
function createATLSheet() { var ss = SpreadsheetApp.create("ATL Futures Age Scanner"); var sheet = ss.getSheetByName("Sheet1"); sheet.setName("Scan Results"); var headers = ["#","Symbol","Age (Days)","First Candle Date", "First Candle Source","Open Price (USDT)","Funding Rate (%)","Listed On", "Scan Date","Month Filter"]; sheet.getRange(1,1,1,headers.length).setValues([headers]); // Header row styling var hr = sheet.getRange(1,1,1,headers.length); hr.setBackground("#080b0f"); hr.setFontColor("#00e676"); hr.setFontWeight("bold"); hr.setFontSize(10); hr.setFontFamily("Courier New"); // Body area styling sheet.getRange("A2:J2000").setBackground("#0d1117"); sheet.getRange("A2:J2000").setFontColor("#e8edf2"); sheet.getRange("A2:J2000").setFontFamily("Courier New"); sheet.getRange("A2:J2000").setFontSize(11); sheet.setFrozenRows(1); sheet.setColumnWidth(1, 45); sheet.setColumnWidth(2, 115); sheet.setColumnWidth(3, 90); sheet.setColumnWidth(4, 135); sheet.setColumnWidth(5, 135); sheet.setColumnWidth(6, 140); sheet.setColumnWidth(7, 115); sheet.setColumnWidth(8, 105); sheet.setColumnWidth(9, 125); sheet.setColumnWidth(10, 105); sheet.setTabColor("#00e676"); // Instructions sheet var inst = ss.insertSheet("Instructions"); var rows = [ ["ATL Futures Age Scanner — Export Guide"],[""], ["HOW TO EXPORT"], ["1. Run the scan in the ATL tool and wait for results."], ["2. OPTION A — Copy for Sheets: click the button, go to Scan Results tab, click A1, paste (Ctrl+V)."], ["3. OPTION B — Google Sheets button: paste this sheet URL into the tool, click Push to Sheet."], ["4. OPTION C — Download CSV: import via File > Import in Google Sheets."], [""],["COLUMN GUIDE"], ["# Row number"], ["Symbol Base asset + USDT (e.g. BTCUSDT)"], ["Age (Days) Days since first detected futures candle"], ["First Candle Date Date of the earliest daily candle found"], ["First Candle Source Which exchange had the earlier listing"], ["Open Price (USDT) Opening price of the very first candle"], ["Funding Rate (%) Current perpetual funding rate at scan time"], ["Listed On Binance / Bybit / Both"], ["Scan Date When this scan was run"], ["Month Filter Which age window was selected (1–6 months)"], [""],["NOTES"], ["Age = futures listing date, not spot or genesis date."], ["Window = selected months × 30.44 days ± 7 days."], ["Funding rate sourced from the exchange with the earlier listing."] ]; inst.getRange(1,1,rows.length,1).setValues(rows); inst.getRange("A1").setFontSize(14); inst.getRange("A1").setFontWeight("bold"); inst.getRange("A1").setFontColor("#00e676"); inst.getRange("A1:A100").setBackground("#0d1117"); inst.getRange("A2:A100").setFontColor("#8892a0"); inst.getRange("A2:A100").setFontFamily("Courier New"); inst.getRange("A2:A100").setFontSize(11); inst.setColumnWidth(1, 520); inst.setTabColor("#5a6470"); var url = ss.getUrl(); Logger.log("Created: " + url); SpreadsheetApp.getUi().alert("Sheet created!\n\nURL: " + url + "\n\nCopy this URL and paste it in the ATL tool's Google Sheets export field."); }
Step 3 — Run it
Click the ▶ Run button. Grant permissions when prompted. The script creates your sheet and shows its URL — copy that URL and paste it into the tool's Google Sheets export field.
